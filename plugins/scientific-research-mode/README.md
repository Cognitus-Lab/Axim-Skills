# Scientific Research Mode

> AXIM-native research orchestration from question to publication with evidence and reproducibility gates.

## Overview

This plugin defines the research discipline used when Scientific Research Mode is enabled in AXIM. It is an original implementation designed for AXIM's existing Odyssey/Magnus routing, local tools, skill engine, memory, RAG, and session storage.

The staged workbench architecture is informed by public open-science practices and by the Apache-2.0 OpenScience project at https://github.com/synthetic-sciences/openscience. No OpenScience source code or skill content is copied into this plugin.

## Lifecycle

1. Question
2. Literature
3. Hypotheses
4. Method
5. Execution
6. Analysis
7. Critique
8. Synthesis
9. Publication

Advancement requires verified evidence, testable hypotheses, a documented method, execution artifacts, and a passing critique.

## Safety

- Never fabricate sources or results.
- Distinguish planned from executed work.
- Preserve parameters, software versions, seeds, and artifact digests.
- Require expert review for clinical, chemical, biological, and other safety-critical outputs.
